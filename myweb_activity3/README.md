## Project Description

This project is a personal student portfolio website created for ICT251 Web Technologies Activity 3. It builds on my Activity 2 website and adds JavaScript interactivity.

## JavaScript Features

The website includes the following JavaScript features:

1. Contact form validation and information preview.
2. Light/dark theme switch.
3. Photo gallery with Previous and Next controls.
4. Study-hours calculator.
5. Expandable project details.

## Main Website Sections

The website contains:

- About Me
- My Hobbies
- My Learning Plan
- Projects and Skills
- My Photos
- My Media
- Contact Me

## Media

The website includes:

- Three student-related photographs.
- An introduction video.
- An audio recording.

## How to Run the Website

1. Download or clone the project folder.
2. Open the project in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Use the navigation menu to explore the different sections.
5. Test the JavaScript features by interacting with the buttons and forms.
